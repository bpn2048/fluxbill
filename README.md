# FluxBill

AI-assisted billing dashboard demo. React + Vite frontend, FastAPI backend with an LLM-powered voice and text assistant.

```
fluxbill/
├── backend/    FastAPI service, AI command planner, Whisper STT
├── frontend/   Vite + React 19 dashboard
└── docs/       Architecture, deployment, local dev guides
```

## Quickstart

```bash
docker compose up
```

Frontend at http://localhost:5173, backend at http://localhost:8000.
